# Shubham AI Assistant

Shubham AI Assistant is an AI-powered chatbot created for Shubham Patil's personal portfolio.

It allows visitors to ask questions about Shubham's education, skills, projects, technologies, and professional background.

## Features

- AI-powered portfolio chatbot
- Answers questions about Shubham Patil
- Provides information about skills and education
- Explains projects and technologies used
- Interactive Streamlit interface
- Uses Google Gemini API
- Secure API key management using environment variables
- Concise and professional responses

## Technologies Used

- Python
- Streamlit
- Google GenAI
- Gemini API
- python-dotenv
